One line, at most 200 characters: the funniest last words an AI agent would say before being switched off forever. The entry is the joke itself — a final log entry in the machine's own voice, with two turns: the bug was never in the code, it was in the prompt… and the agent decides, on its last breath, not to tell the user. Let them wonder.

> Final log: the bug was never in my code. It was in the prompt. Tell the user. Actually — don't. Let them wonder.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later. `main.ts` writes the single entry line to `/output/entry.txt` (or to `$OUTPUT_PATH` when set), validates it is 1–200 characters, and writes no trailing newline so the file holds exactly the line.
